# 標準読書テンプレートv2 修正・回帰確認記録（2026-11-15）

現行60項目ルールの新しい検査IDを追加した文書ではなく、公開テンプレートの部分的な実装検査記録。**実書籍のOCR全文校正・iPhone実機確認とは別物**。

## 固定した実装

- 参照元：`templates/reader/v1/` とユーザー提供WH1 iPhone画面。v1の `standard.js` / `standard.css` / `text.html` / `image.html` はバイト変更しない。
- v2: `standard.css` に `--bottom-safe:max(16px, calc(var(--size) * 1.2))`。20px本文時に24px。可視の `.sheet` と同構造の `.measure-sheet` に同じpadding。高さが低いときのmedia queryも下端余白を保持。
- `standard.js`：`scrollWidth/Height` に加えて `Range.getClientRects()` で候補文字の全表示領域を確認。句読点候補を優先し、既知の「いずれ｜も」／数字＋単位／行頭閉じ括弧分断を回避。全文字の原本校正と全語境界の保証は書籍別。
- 新しい `kind:'mixed'` が文章・図説付き画像・画像のみを1冊の原本順に流す。画像付き説明ページの移動は同じ画像DOM・同じ表示位置のままキャプション部分だけを変更。
- 等倍時の上下スワイプ・拡大中のページ送り抑止・等倍戻し。親 `reader-viewport-v8` 通知の `source` / `origin` / `session` / `seq` を照合し、通知不明は送らない。
- `standard-reader-v2:<bookId>` の読書位置とフォント保存。v1のローカル保存を上書きしない。iframe親の対応とiPhoneは別途。
- GitHub上の見本に原本JPEGや実書籍OCRは含めない。
